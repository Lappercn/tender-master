# 企业数据管理工具说明

## 概述

`test.py` 是一个用于管理企业数据的Python脚本，已优化以适配新的前端数据结构。该工具支持将各行业Top10企业/机构名单存储到MongoDB数据库中。

## 主要功能

### 1. 数据结构适配
- ✅ 适配新的前端Company接口
- ✅ 添加了`status`、`priority`等必需字段
- ✅ 支持可选字段：`website`、`contact`、`description`、`tags`、`region`、`scale`等
- ✅ 使用UTC时间戳
- ✅ 增强的数据验证功能

### 2. 操作模式

#### 插入模式 (insert)
```bash
# 清空现有数据并插入新数据（默认）
python test.py --mode insert --clear

# 保留现有数据并插入新数据
python test.py --mode insert --no-clear
```

#### 更新插入模式 (upsert)
```bash
# 逐个检查并更新或插入数据
python test.py --mode upsert
```

#### 统计模式 (stats)
```bash
# 查看当前数据库统计信息
python test.py --mode stats
```

## 环境配置

### MongoDB连接
设置环境变量：
```bash
export MONGO_URI="mongodb://localhost:27017/hawkeye"
```

或在Windows中：
```cmd
set MONGO_URI=mongodb://localhost:27017/hawkeye
```

### 日志配置
脚本会自动创建日志文件：`logs/industry_companies_mongo.log`

## 数据结构

### 企业数据字段

| 字段名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| company_name | string | ✅ | 企业名称 |
| industry | string | ✅ | 所属行业 |
| rank | number | ✅ | 行业排名 |
| company_type | string | ✅ | 企业类型 |
| status | string | ✅ | 状态（默认：active） |
| priority | string | ✅ | 优先级（默认：medium） |
| note | string | ❌ | 备注信息 |
| website | string | ❌ | 官方网站 |
| contact | string | ❌ | 联系方式 |
| description | string | ❌ | 企业描述 |
| tags | array | ❌ | 标签列表 |
| region | string | ❌ | 所在地区 |
| scale | string | ❌ | 企业规模 |
| contact_info | object | ❌ | 详细联系信息 |
| business_history | array | ❌ | 业务历史 |
| created_at | datetime | ✅ | 创建时间 |
| updated_at | datetime | ✅ | 更新时间 |

## 索引优化

脚本会自动创建以下索引以提高查询性能：

- 复合索引：`(industry, rank)`
- 单字段索引：`company_name`、`company_type`、`status`、`priority`
- 时间索引：`created_at`（降序）
- 文本搜索索引：`(company_name, note, description)`

## 数据验证

脚本包含数据验证功能，确保：
- 必需字段不为空
- 数据类型正确
- 跳过无效数据并记录警告

## 使用示例

### 1. 首次导入数据
```bash
python test.py --mode insert --clear
```

### 2. 增量更新数据
```bash
python test.py --mode upsert
```

### 3. 查看数据统计
```bash
python test.py --mode stats
```

## 注意事项

1. **数据备份**：在使用`--clear`选项前，请确保已备份重要数据
2. **网络连接**：确保MongoDB服务正在运行且可访问
3. **权限**：确保有足够的数据库读写权限
4. **日志监控**：定期检查日志文件以了解操作状态

## 故障排除

### 常见问题

1. **连接失败**
   - 检查MongoDB服务状态
   - 验证MONGO_URI配置
   - 确认网络连接

2. **数据验证失败**
   - 检查必需字段是否完整
   - 查看日志文件中的详细错误信息

3. **索引创建失败**
   - 确认数据库写权限
   - 检查是否有重复的索引定义
