# 千里马网招标信息爬虫

## 项目简介

本项目是一个基于Selenium和undetected-chromedriver的千里马网招标信息爬虫，能够自动登录千里马网站，搜索指定企业的招标信息，并将数据保存到MongoDB数据库中。

## 核心功能

- 🔐 **自动登录**：支持千里马网站的密码登录
- 🔍 **智能搜索**：按企业名称搜索招标信息，支持"招标单位"搜索类型
- 📊 **数据提取**：提取招标公告的详细信息
- 💾 **实时保存**：爬取一页立即保存一页，避免数据丢失
- 🛡️ **反检测**：使用undetected-chromedriver避免被网站检测
- 🎭 **人性化模拟**：模拟真实用户行为（随机延迟、鼠标悬停、逐字符输入等）

## 爬虫逻辑流程

### 1. 初始化阶段
```
1. 连接MongoDB数据库
2. 从数据库获取企业名单（330家企业）
3. 初始化WebDriver（无头模式Chrome浏览器）
4. 配置反检测参数
```

### 2. 登录阶段
```
1. 打开千里马网登录页面
2. 切换到"密码登录"模式
3. 模拟人工输入用户名和密码（逐字符输入+随机延迟）
4. 点击登录按钮并等待登录完成
```

#### 搜索阶段
1. 进入搜索页面
2. 模拟点击"招标信息"标签（无论是否已选中都执行点击操作）
3. 选择"招标单位"搜索类型
4. 设置"近一年"时间筛选
5. 输入企业名称（模拟人工逐字符输入）
6. 处理可能的遮罩层干扰
7. 点击搜索按钮

### 4. 数据提取阶段
```
1. 逐页爬取招标信息（最多5页）

2. 模拟用户浏览行为（页面滚动、停顿等）
3. 提取每条招标公告的详细信息
4. 实时保存到MongoDB（爬取一页保存一页）
5. 记录详细的爬取日志
```

### 5. 循环处理
```
1. 处理完一家企业后，随机延迟3-6秒
2. 继续处理下一家企业
3. 直到处理完所有330家企业
```

```json
  "detail_summary": "详情页摘要信息（字符串）"
}
```

## 技术特性

### 详情页处理说明
- 摘要信息来源：详情页 id="summaryTable" 的表格，过滤 class="none" 的行；解析每一行的“标签: 值”，去除空值与无关字样并以分号拼接，保存到 detail_summary 字段。
- 详情正文来源：详情页 id="detailInfoContainer" 区域的纯文本，去除脚本样式等无关内容，保存到 detail_txt 字段。
- 空值策略：当无法获取或页面不存在上述元素时，detail_txt 与 detail_summary 均保存为空字符串，以确保字段类型稳定。

### 反检测机制
- 使用`undetected-chromedriver`避免被识别为自动化程序
- 设置真实的User-Agent和浏览器参数
- 隐藏WebDriver标识和自动化特征
- 独立的用户数据目录

### 人性化模拟
- **随机延迟**：各种操作间的随机等待时间
- **逐字符输入**：模拟真实用户的打字速度
- **鼠标行为**：模拟鼠标悬停、点击等操作
- **页面浏览**：模拟用户滚动浏览页面内容
- **思考时间**：在关键操作前模拟用户思考
- **强制标签点击**：无论"招标信息"标签是否已选中，都执行模拟点击操作，确保流程一致性

### 错误处理
- **多重点击策略**：ActionChains点击 → XPath文本定位点击 → JavaScript直接点击
- **标签点击保障**：针对"招标信息"标签提供三重点击机制，确保操作成功
- **遮罩层处理**：自动检测并关闭页面遮罩层
- **JSON序列化**：安全处理MongoDB ObjectId等特殊类型
- **详细日志**：记录每个步骤的执行情况和错误信息

## 使用方法

### 1. 环境准备
```bash
pip install selenium undetected-chromedriver pymongo
```

### 2. 配置信息
在脚本中修改以下配置：
```python
USERNAME = "your_username"  # 千里马网用户名
PASSWORD = "your_password"  # 千里马网密码
```

### 3. 数据准备
确保MongoDB中存在企业名单数据：
```python
# 运行 industry_companies_to_mongo.py 导入企业数据
python industry_companies_to_mongo.py
```

### 4. 运行爬虫
```bash
python new_spider.py
```

## 注意事项

1. **网络稳定性**: 确保网络连接稳定，避免中途断网
2. **账号安全**: 使用有效的千里马网VIP账号
3. **反爬限制**: 脚本已内置反检测机制，但仍需注意使用频率
4. **数据去重**: 基于`contentId`自动去重，避免重复保存
5. **资源占用**: 无头模式运行，资源占用较低

## 故障排除

### 常见问题
1. **登录失败**: 检查用户名密码是否正确
2. **元素定位失败**: 网站页面结构可能发生变化
3. **数据库连接失败**: 检查MongoDB服务是否启动
4. **Chrome版本问题**: 确保Chrome浏览器版本与chromedriver兼容

### 日志分析
查看`logs/new_spider.log`文件，根据错误信息进行问题定位。
