# 字段提取逻辑说明 (Regex Rules)

本文档记录了 `wj_ccgp_chongqing.py` 及 `wj_sgcc_china.py` 等爬虫中使用的关键字段提取逻辑，特别是针对不同公告格式的正则表达式匹配规则。

## 1. 预算金额 (Budget)
按优先级顺序匹配，提取数值及单位（万/元）：
1.  `r'(预算金额|预算总金额|项目预算).*?([\d,]+(\.\d+)?).*?(万|元)'`
2.  `r'(最高限价|最高限制单价|最高单价限价|限价|招标控制价|投标限价|最高投标限价).*?([\d,]+(\.\d+)?).*?(万|元)'`
3.  `r'(采购控制价|控制价).*?([\d,]+(\.\d+)?).*?(万|元)'`
4.  `r'(合同估算价|估算价|项目概算|概算金额|项目投资).*?([\d,]+(\.\d+)?).*?(万|元)'`
5.  `r'(资金来源|出资比例).*?([\d,]+(\.\d+)?).*?(万|元)'`
6.  `r'(单价|金额|价格).*?([\d,]+(\.\d+)?).*?(万|元)'`

## 2. 截止时间 (Tender End Time)
匹配各类截止时间描述，优先提取具体日期时间：
1.  `r'(递交|提交).*?(截止时间|结束时间).*?([\d]{4}年[\d]{1,2}月[\d]{1,2}日(\s*[\d]{1,2}:[\d]{1,2})?)'`
2.  `r'(投标|响应|报价|比选|申请文件).*?(截止时间|结束时间).*?([\d]{4}年[\d]{1,2}月[\d]{1,2}日(\s*[\d]{1,2}:[\d]{1,2})?)'`
3.  `r'(开标时间|开启时间|开标).*?([\d]{4}年[\d]{1,2}月[\d]{1,2}日(\s*[\d]{1,2}:[\d]{1,2})?)'`
4.  `r'(报名).*?(截止时间|结束时间).*?([\d]{4}年[\d]{1,2}月[\d]{1,2}日(\s*[\d]{1,2}:[\d]{1,2})?)'`
5.  `r'([\d]{4}年[\d]{1,2}月[\d]{1,2}日(\s*[\d]{1,2}:[\d]{1,2})?).*?截止'`

## 3. 采购人/招标单位 (Purchaser/Tenderees)
兼容多种称呼，提取冒号后的内容：
1.  `r'(采购人|采购单位|招标人|招标单位|需求单位|业主单位|建设单位|发包人|项目业主|招商人|采购单位名称)[：:]\s*(.+)'`
2.  `r'(采购人名称|招标人名称)[：:]\s*(.+)'`

## 4. 代理机构 (Agent)
兼容多种称呼，提取冒号后的内容：
1.  `r'(代理机构|招标代理|招标代理机构|采购代理|采购代理机构|代理单位|招标服务单位|比选代理机构)[：:]\s*(.+)'`
2.  `r'(代理机构名称)[：:]\s*(.+)'`

## 5. 采购方式 (Purchase Method)
提取项目类型或采购方式：
1.  `r'(采购方式|招标方式|选取方式|运作方式)[：:]\s*(.+)'`
2.  `r'(项目类型)[：:]\s*(.+)'`

## 6. 中标信息 (Winning Bidder & Amount)
提取中标人及中标金额，主要用于中标/成交公告：
1.  **中标人**: `r'(中标人|中标单位|成交人|成交供应商|成交单位|供应商名称|中标供应商|第一中标候选人|预中标单位|中标单位名称)[：:]\s*(.+)'`
2.  **中标金额**: `r'(中标金额|中标价格|成交金额|成交价格|投标报价|中标价).*?([\d,]+(\.\d+)?).*?(万|元)'`

## 7. 联系信息 (Contact Info)
**存储逻辑**：
不再使用单一字符串存储，而是采用**对象数组**格式 `contacts`，支持存储多个联系人及其对应电话，彻底解决多联系人混淆问题。
- 数据结构：`List[Object]` -> `[{"name": "张三", "phone": "023-12345678"}, ...]`
- 数据库字段：`contacts`

**提取逻辑**：
为了防止联系人与电话错配（如将采购人的电话配给代理机构联系人），采用**组合匹配**策略，优先提取“姓名+电话”紧邻出现的组合。

1.  **组合匹配 (High Priority - 推荐)**:
    *   正则：`r'(项目联系人|联系人|负责人|联系方式|技术咨询|商务咨询|异议联系人)[:：]\s*([\u4e00-\u9fa5]{2,4}).{0,50}?(联系电话|电话|手机)[:：]\s*([\d-]{8,})'`
    *   说明：查找距离姓名 50 字符以内的电话号码，确保归属关系。提取到的每一组 (Name, Phone) 都会作为一个对象存入 `contacts` 数组。

2.  **单项匹配 (Fallback - 兜底)**:
    *   仅当组合匹配未找到任何结果时触发。
    *   联系人: `r'(项目联系人|联系人|负责人|技术咨询|商务咨询|异议联系人)[：:]\s*([\u4e00-\u9fa5]{2,4})'`
    *   联系电话: `r'(联系电话|电话|手机|联系方式)[：:]\s*([\d-]{8,})'`
    *   说明：若仅匹配到单项，将构造一个包含单一信息的对象存入数组。

## 8. 附件下载链接 (Attachment URL Construction) - 国家电网特殊逻辑
针对国家电网 (SGCC) 平台，附件链接往往无法直接从 `<a>` 标签获取，需通过 URL 参数动态构造。
- **来源**: 详情页 URL 参数 `noticeId` 和 `noticeDetId`。
- **构造公式**: `https://ecp.sgcc.com.cn/ecp2.0/ecpwcmcore//index/downLoadBid?noticeId={noticeId}&noticeDetId={noticeDetId}`
- **触发条件**: 当正文中包含“下载”或“附件”关键字，且 URL 中存在 ID 参数时自动构造。

---
**说明**：所有正则匹配均采用非贪婪模式，并兼容中文冒号（：）和英文冒号（:）。提取逻辑优先使用详情页（正文）的匹配结果，若未匹配到则回退使用列表页抓取的信息。
